# Playwright Async Web Scraper & RPA Bot

An asynchronous web scraping and automation engine built with **Python** and **Playwright**. Designed for extracting structured data, automating multi-page workflows, and dynamic UI interactions.

## 🚀 Features
- **Async Execution**: Leverages `asyncio` for non-blocking browser automation.
- **Robust Locators**: Uses Playwright's native role-based locators for high reliability.
- **Structured Data Export**: Automatically formats and saves results into JSON format.
- **Modular Design**: Encapsulated object-oriented architecture for scalable RPA workflows.

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Framework**: Playwright (Async API)
- **Data Format**: JSON
